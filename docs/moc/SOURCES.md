# Source inventory
Official FRED public series: STLFSI4, NFCI, ANFCI, BAMLH0A0HYM2, VIXCLS, SOFR, TGCR, DGS10, DGS30.
URL pattern: https://fred.stlouisfed.org/series/SERIES
CSV pattern: https://fred.stlouisfed.org/graph/fredgraph.csv?id=SERIES
Weekly series must not be treated as available at the observation date without checking release time.
Spread units: BAMLH0A0HYM2 and SOFR/TGCR are percent, not bp.
Pending official adapters: https://www.financialresearch.gov/financial-stress-index/ and https://www.newyorkfed.org/markets/benchmarks/sofr and https://www.cboe.com/tradable_products/vix/ .
