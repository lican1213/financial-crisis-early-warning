# ADR-0003: data-rich monitoring instead of an unsolicited weekly report

**Date:** 2026-11-09. **Decision:** Adopt research-as-context, not a new combined alert family.

**First-principles question:** Can a source with no fresh observation prove that there is no financial crisis? No. Can a GDP/jobs/housing release alone establish system funding contagion? No. Can a technical four-family green downgrade an independently assessed six-module orange? No, absent calibration.

The ChatGPT `金融危机周报` automation was paused by explicit user request on 2026-11-09. FCEWS continues its independent conditional hourly risk watch. Retire weekly scheduling claims in documentation, but **retain** the last dated human six-module orange baseline as historical context.

Research becomes an independently scheduled daily, no-alert dataset: US BLS/DOL rates via official FRED bridge, and a future vetted NBS/PBOC/issuer-release ledger. Revisions and unavailable data must be expressed, not filled with cached or guessed data. A live official data fetch is not the original as-published vintage.

Structural scoring separation: four-family systemic severity remains `unknown` where the human macro model cannot be compared, with `model_comparability=not_calibrated`. Recruiting and China macro scores are unknown until coverage and scoring rules pass their own evidence gates.

Operational distinction: adding a second GitHub schedule at minute 43 and checking source-health reduces failure exposure but **cannot fix GitHub's best-effort cron guarantee**. Independent ChatGPT source checking is a fallback monitoring path, not a machine-triggered GitHub rerun.

Consequences: no weekly notification noise, concrete provenance and adversarial tests, but no claim of a now-validated crisis predictor or fully automated Chinese government table extraction.
